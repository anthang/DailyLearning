# Daily Learning

Tableau de bord éducatif pour Windows avec Rainmeter et Python.

## Fonctionnalités prévues

- Histoire et géographie
- Culture générale insolite et utile
- Anglais : vocabulaire, sens selon le contexte et expressions
- Chinois mandarin : caractères, pinyin et traductions
- Quiz interactifs de vocabulaire
- Veille cybersécurité : actualités, attaques, outils et analyses
- Actualisation automatique toutes les heures

## Technologies

- Rainmeter : interface Windows
- Python : gestion et actualisation des contenus
- Git : gestion des versions
- WSL Ubuntu : environnement de développement
